# Ωράριο εργασίας — έκδοση για Vercel Drop

Η φόρμα εμφανίζει ζωντανά την πραγματική διάρκεια και δίπλα τις ώρες πληρωμής, στρογγυλεμένες στο πλησιέστερο 15λεπτο. Για παράδειγμα, 03:01 → 03:00 και 03:08 → 03:15. Οι βάρδιες που περνούν τα μεσάνυχτα υπολογίζονται επίσης.

Η «Υποβολή» ανοίγει σε νέα καρτέλα την επιβεβαίωση της υπάρχουσας Google Form. Έλεγξε ότι η Google εμφανίζει μήνυμα καταχώρισης. Οι ώρες πληρωμής εμφανίζονται στην οθόνη· δεν αποθηκεύονται ως ξεχωριστή απάντηση στη φόρμα.

Σύρε τον αποσυμπιεσμένο φάκελο `orario-ergasias-static` στη σελίδα του υπάρχοντος έργου `orario-ergasias` στη Vercel και επίλεξε «Deploy to Production».
